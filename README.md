# TDEE 熱量計算器

一款使用 UIKit 製作的 iOS App，可依使用者的生理性別、年齡、身高與體重計算基礎代謝率（BMR），再根據活動程度估算每日總熱量消耗（TDEE）。

## 功能特色

- 選擇男性或女性，輸入年齡、身高與體重
- 即時檢查輸入內容並顯示錯誤提示
- 使用 Mifflin–St Jeor 公式計算 BMR
- 透過滑桿選擇每週運動天數
- 支援長時間運動或體力勞動模式
- 依活動程度顯示對應圖片、活動係數與 TDEE
- 提供以 TDEE 減少 300 大卡為基準的減重攝取建議

## 計算方式

### 基礎代謝率（BMR）

- 男性：`9.99 × 體重（kg）+ 6.25 × 身高（cm）− 4.92 × 年齡 + 5`
- 女性：`9.99 × 體重（kg）+ 6.25 × 身高（cm）− 4.92 × 年齡 − 161`

### 每日總熱量消耗（TDEE）

`TDEE = BMR × 活動係數`

| 活動程度 | 判定方式 | 活動係數 |
| --- | --- | ---: |
| 趨於靜態 | 幾乎不運動 | 1.2 |
| 較低 | 每週運動 1–3 天 | 1.375 |
| 正常 | 每週運動 4–5 天 | 1.55 |
| 較高 | 每週運動 6–7 天 | 1.72 |
| 激烈 | 長時間運動或從事體力勞動 | 1.9 |

選擇「我想減重」時，App 會顯示 `TDEE − 300 大卡` 的每日建議攝取量，並提醒攝取熱量不應低於 BMR。

## 操作流程

1. 選擇生理性別。
2. 輸入 1–100 歲的年齡，以及大於 0 的身高與體重。
3. 查看自動計算出的 BMR。
4. 前往 TDEE 頁面，選擇一般或減重模式。
5. 設定每週運動天數；若有長時間運動或體力勞動，開啟對應開關。
6. 查看活動等級、計算公式與每日熱量結果。

## 開始使用

1. Clone 此 repository。
2. 使用 Xcode 開啟 `hw8_TDEE.xcodeproj`。
3. 選擇 iPhone Simulator 或實機。
4. 按下 Run（`⌘R`）建置並執行 App。

此專案未使用第三方套件。

## 注意事項

計算結果僅供日常熱量規劃與學習參考，不能取代醫師、營養師或其他專業醫療建議。實際熱量需求會受到健康狀態、身體組成與生活型態等因素影響。
